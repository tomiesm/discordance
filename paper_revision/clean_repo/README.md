# Executed revision pipeline snapshot

This directory preserves the pipeline used for the initial intercept correction
and its propagation. Later analyses and corrected donor aggregation are in the
[parent revision guide](../README.md), which defines the final analysis sequence.
The [root README](../../README.md) describes the current manuscript.

Scientific Python files are copied unchanged from the verified source archive.
The historical configuration retains the original local HEST path; edit it for
your data location. The `revision_01_*` scripts require archived inputs from the
original workspace. Their original prediction groups must not be interpreted
as biological discovery patients.
